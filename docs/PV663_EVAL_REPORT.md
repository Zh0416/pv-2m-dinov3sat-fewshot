## 4. 核心科学结论与退化机理诊断

1. **三模块主干 `M3_Off_R`（纯冻结 DINOv3-SAT，免训练）跨数据集泛化极强**：
   - 在 116 个完全未见地理站点（510 张图）上全面大幅领先基线 `B0_32_Ref`：
     - **1-shot**：`116/116` 站点全胜，`Dice +0.1492`（`0.6344 → 0.7836`），`PosBgFP` 降 **68%**（`0.1129 → 0.0360`），`BF1@2px` 达到 **2.3×**；
     - **3/5-shot**：`115/116` 与 `110/116` 站点胜出，5-shot 宏平均 **`Dice = 0.8640, IoU = 0.7998, AP512 = 0.9256, BF1@2px = 0.5837`**，大目标 `Dice = 0.9423`（`Det = 100%`），极小目标 `<1%` 召回暴涨 `+17.7%`（`56.0% → 73.7%`）。
2. **模块 ③ `M3_Deformable_Grad` 在高清 `PV663` 上出现显著跨分辨率退化（客观阴性边界）**：
   - 尽管 `Stage3_R_DeformGrad` 仍大幅领先 `B0_32_Ref`（`+0.1465 / +0.0652 / +0.0539` Dice），但相对上游 `M3_Off_R` 在三档均出现统计显著退化（5-shot `BF1@2px -0.0610`, `Dice -0.0111`，仅 `16/116` 站点获益；触发 `4,051` 次拓扑回退）。
   - **逐图根因分析**：
     - 受损最严重的 5 张图在 `M3_Off_R` 上原本边界就已经极准（例如 `PV08_334929_1196660.bmp`：`M3_Off_R` 已达 `Dice=0.9725, BF1@2=0.9384`，精修后反而跌至 `BF1@2=0.4282`）；
     - 受益最大的 5 张图则全是 `M3_Off_R` 原本边界模糊偏移的样本（如 `PV08_334056_1181429.bmp`：`BF1@2 0.3113 → 0.5886, +0.2773`）。
   - **本质机理**：`PV663` 为原生 `1024×1024` 高清（`0.8 m`）影像，上游 `M3_Off_R` 边界已足够锐利（`BF1@2 = 0.584`）；无符号 Scharr 梯度在高清图上对**光伏板内部行间亮缝、紧邻路缘和堤坝**响应极强，叠加为 2m 影像标定的偏宽松门限 `tau_deform = 0.20`，导致原本对齐的轮廓被拉偏 `~3.6 px`。
   - **工程结论**：**在高清（$\le 1\text{ m}$）光伏影像上默认应关闭无符号梯度精修，直接使用纯冻结三模块主干 `M3_Off_R`（`Dice=0.8640, BF1@2=0.5837`）**；若希望模块 ③ 具备跨分辨率普适性，下一步应加入「粗边界梯度对齐度自检门控（已对齐高置信边锁零位移）+ 语义内外有符号对比度约束」。
