### 0.2 既有机制、待证假设与实验通过的新增贡献（严格区分）

1. **既有机制（来自历史 `M3_Pruned_Ref`，本次仅做无损模块化拆分）**：
   - 冻结 `DINOv3-SAT`（`ViT-L/16`）双尺度深层特征（`deep_32`, `deep_64`, blocks 20–23）+ 中层特征（`mid_64`, blocks 12–15）与特征缓存；
   - 模块 ① 原版：前景 Top-3（`top2_soft` 聚合）减背景 Top-3（`0.50` 权重）双尺度融合 + 中层软否决 + 支持集 LOO / 1-shot 排除邻域的 `bias/temp` 校准；
   - 模块 ② 原版：基于高置信种子的图内自对比残差（Self-Rescue，`S_self` + 受限 $\Delta_{\rm self}$）；
   - 模块 ③ 原版：64 网格 5×5 DINO 特征亲和传播（$\eta=0.45$，2 步）+ 512 双线性上采样（`P_coarse`）+ `0.50` 阈值粗掩膜（`M_coarse`）。
2. **本次被证伪 / 未通过的待证假设**：
   - **假设 ①（未通过）**：从同 episode 支持集筛选光伏混淆度最高的背景 token 子库 $H$ 做二次 margin 扣分并重新校准，能够显著压低查询纯负图误检。实验表明在 `K=1` 因压低支持背景分布导致阈值下移反而恶化 `NegFP`（`+0.0169`），在 `K=3/5` 虽略优于等预算随机背景，但远未触及 `Gate-FP` 门槛，且对未出现在支持集中的查询大棚（如 `PV-93`）无效。
   - **假设 ②（Stage 0 中止）**：在未阈值化 $S_{\rm sem}$ 上通过局部相对突出度无需强种子即可稳定圈定原模型漏检的小光伏组件，进而通过 128→512 局部放大重编码补漏。Stage 0 离线覆盖审查表明：4 窗预算下对漏检 GT 组件的覆盖率仅为 `11.87% / 22.31% / 24.82%`（全部低于预设 `25%` 门限），且在纯负图上 100% 触发；全图 token 对照虽能提高无种子召回，但导致纯负图 `NegFP` 恶化 `+0.0046 ~ +0.0067` 并拖累 `AP512`。
3. **本次实验通过的新增贡献（局限边界同时说明）**：
   - **架构贡献**：完成 `M3_Pruned_Ref` 到 `pvfs/modules/{contracts,semantic,recovery,boundary,pipeline}.py` 的零误差三模块解耦（120 episodes 全量逐查询 `max_diff = 0.0`、`0` 像素翻转），建立清晰的接口契约与独立模块消融框架。
   - **算法贡献（模块 ③ `M3_Deformable_Grad`）**：在固定上游 `P_coarse / M_coarse` 下，将免训练像素级轮廓精修从旧版「刚性整段平移」升级为「共享端点法向的窄带多控制点分段线性变形 + 闭环动态规划 + Scharr 原图梯度 + `P_coarse` 外移护栏 + 拓扑安全回退」。**需要诚实说明**：动态规划、Scharr 梯度与法向采样均为经典工具；本轮验证的核心是该免训练局部变形几何在 2 m 遥感光伏粗掩膜精修任务上，相比原版 `R` 与旧刚性几何均取得了跨 4 折一致且统计显著的 `BF1@1px / BF1@2px / Dice` 同步增益（具体移动预算与离线可达参考的局限见第 4.4 节）。

### 2.3 失败机理与最差负样本诊断
1. **`K=1` 校准漂移放大误检**：1-shot 中仅 1 张支持图，难负例库 $H$ 来自支持图自身高混淆背景；重算支持图背景分数时，支持图自身背景被精准大幅压低（$t_H = 0.235$，平均扣分 `0.051`），直接拉低校准分位数 `bg_s q95` 与 `bias`。结果查询图整体概率上抬（`Recall +0.0505`，匹配召回所需阈值升至 `0.593`），但即使在匹配召回处 `NegFP` 仍从 `0.0341` 恶化至 `0.0408`（且 1/40 episode 因有效背景不足触发 `below_min_total_tokens` 弃权）。
2. **`K=3/5` 信息冗余与未见混淆物失灵**：`K=3` 时 `HardNegH` 确实在 4/4 折优于等预算随机背景（`dNegFP = -0.0016`, `CI95 [-0.0031, -0.0003]`），说明混淆筛选方向本身有微弱信号；但相对原版 `R`（已有全背景 Top-3 与中层软否决），`NegFP` 仅下降 `-0.0010`（等召回处仅 `-0.0005`），远低于 `Gate-FP` 要求的 `-0.005`，且 `Dice` 下降 `-0.0022`；到 `K=5` 时全背景库已足够丰富，二次惩罚反而使 `NegFP` 微升 `+0.0012`。
3. **典型最差负样本（大棚/规则人造地物，`K=5` 与 `K=1`）**：
   - `K=5`：`负样本/PV-93.tif`（fold 2，`BaseR 0.2266 -> HardNegH 0.2258`，几乎不动）、`负样本/PV-100.tif`（fold 1，`0.1007 -> 0.1064`）、`负样本/PV-96.tif`（fold 1，`0.0760 -> 0.0778`）、`负样本/PV-86.tif`（fold 3，`0.0177 -> 0.0269`）、`负样本/PV-92.tif`（fold 2，`0.0143 -> 0.0191`）。
   - `K=1`：`PV-96.tif` 从 `0.1108` 恶化至 `0.1775`（`+0.0667`），`PV-100.tif` 从 `0.0940` 恶化至 `0.1372`（`+0.0431`），`PV-83.tif` 从 `0.0493` 恶化至 `0.0840`（`+0.0347`）。核心根源在于**支持集中未必包含与查询图同类型的大棚混淆物**，仅靠支持集内部挖难负例无法覆盖跨站点新混淆类别。

**决策**：拒绝模块 ① 候选改动，保持 **原版 `R`**。

## 3. Stage 2 — 模块 ② 独立验证：无种子局部放大复查（Stage 0 中止）

### 4.4 诚实局限、典型成功/失败案例与归因注记
1. **移动预算差异注记（不可过度解读归因）**：在 `K=3/5`，`M3_Deformable_Grad` 移动了 `30.15% / 31.00%` 的弧长（因环级门限 `tau_deform=0.20` 低于旧刚性段级门限 `tau_rigid=0.63`，后者仅移动 `14.99% / 14.22%`），因此 3/5-shot 对 `Rigid_Grad` 的 `+0.0300 / +0.0212` 增益同时包含了「更高变形自由度」与「更大移动比例」两方面因素。但关键反证在于：① `Deformable_Grad` 的平均绝对位移反而**更小**（`3.88 / 3.53 px` vs `4.70 / 4.35 px`），说明不是靠粗暴大幅外扩得分；② 在 `K=1` 两者移动弧长几乎一致（`2.88%` vs `2.67%`）且 `Deformable_Grad` 位移近乎减半（`2.80 px` vs `5.04 px`）时，`Deformable_Grad` 仍全指标领先 `Rigid_Grad`（`BF1@1 +0.0029`, `BF1@2 +0.0021`, `Dice +0.0020`）。未来若做进一步对比，应在相同移动弧比例下做等预算扫参。

3. **5-Shot 代表性收益最大与下降最差样本（`M3_Deformable_Grad vs M3_Off_R`）**：

## 7. 下一步定向迭代建议（供后续单模块调优参考）

1. **模块 ①（最高优先级，决定全三档 `Gate-Net` 是否过门）**：既然支持集内难负例无法覆盖查询图新出现的温室大棚（`PV-93 / PV-100 / PV-96`），下一轮应考虑**图像级/区域级物理或跨层特征一致性**（例如在 `PV-93` 这类高概率误检区域上，检验 DINO 多层特征/颜色-结构纹理或无标签场景背景自对比能否区分塑料大棚反光与光伏深蓝规整阵列），而不是只在支持集内重采样背景 token。
2. **模块 ②**：若继续探索无种子补漏，首要解决的不是重编码，而是**提议器的纯负图拒识门限**（把 100% 纯负图触发率压低到 `<20%` 以下）以及提升极小目标（`<1%`）在全图特征中的弱响应检出率。
3. **模块 ③**：已通过全部预注册门槛，后续可做两项干净的定向迭代：① 针对 `PV-47 / PV-65 / PV-23` 这类「原本 `M_coarse` 已高置信对齐」的边界，引入边界置信度自适应门限或梯度方向（法向对齐的内外符号约束）以防止被邻近非光伏强边拉偏；② 将「整环回退（1,803 次）」升级为「局部冲突弧段回退」，释放被误锁定的正确变形弧段。
