# 阵列相位边界精修模块（Phase Boundary Refinement）预注册方案与锁定协议

> **预注册声明**：本文档与 `configs/phase_boundary_locked.json` 在读取任何真实查询集对照评估结果之前编写并锁定。所有超参数、几何约束、支持集经验门槛规则、等移动预算对齐规则与验收门槛均预先固定；若真实 Dev 集上未达到主要效果门或相位归因门，必须如实报告阴性或证据不足结论，严禁事后调参或更换指标。

---

## 1. 研究问题与模块定位

**核心研究问题**：从已识别光伏阵列内部估计并冻结的二维空间载波相位，能否预测粗边界附近的像素归属，并提供独立于频率、幅值与窄带搜索的像素级边界定位收益？

- **基线模型**：`pvfs/iter5_methods.py` 中的 `M3_Pruned_Ref`（`run_iter5_episode`）。
- **接入位置**：接在 `M3_Pruned_Ref` 的 $64\times 64$ DINO 亲和传播（`propagate_affinity`）和 $512\times 512$ 双线性上采样之后。
- **零侵入保证**：不修改冻结 `DINOv3-SAT` 主干、原型匹配、支持集分位数校准、自对比补漏或亲和传播。所有消融变体（`A` 至 `H`）共享同一次 `M3_Pruned_Ref` 推理得到的连续概率图 $P_0 \in [0, 1]^{512\times 512}$、粗二值掩膜 $M_0(x) = \mathbf{1}[P_0(x) \ge 0.5]$、查询原图 RGB 及当前 Episode 的 $K$ 张带标注支持图。当精修开关关闭（组 `A`）时，输出与 `M3_Pruned_Ref` 逐像素完全一致。

## 2. 几何表示、信号趋势去除与走廊构造（2.1 节锁定规则）

1. **坐标系与像素中心约定**：
   - 图像尺寸为 $512\times 512$，数组索引为 `(row, col) = (y, x)`，二维笛卡尔坐标记为 $x = (x_{\text{col}}, y_{\text{row}})^\top \in \{0, 1, \dots, 511\}^2$，像素中心位于整数坐标处。
   - 非整数坐标采样（如双侧周期终止对照 `D` 中的 $y \pm v/2$）统一采用双线性插值（`align_corners=True`，以整数网格点为中心）。
   - 首版固定全局标注偏置 $\delta_{\text{gt}} = 0$。

2. **连通性与轮廓分段**：
   - 前景 $M_0=1$ 采用 **8-连通**（$3\times 3$ 全 1 结构元），背景 $M_0=0$ 采用 **4-连通**（十字结构元），遵循经典 `(8, 4)` 数字拓扑配对。
   - 面积小于 `min_component_area_px = 64` 的连通域跳过载波拟合，保持原掩膜不变（记录回退原因 `component_too_small`）。
   - 提取每个连通域的有序边界像素链（外边界及内部孔洞边界），计算平滑切向与指向背景（$M_0=0$）的单位外法线 $n_s \in \mathbb{R}^2$（$\|n_s\|_2 = 1$）。
   - 按弧长每 `target_segment_arc_len_px = 16` 像素分段（最短保留段长 `min_segment_arc_len_px = 8`）；当相邻切向转角超过 `corner_split_angle_deg = 45.0°` 时在角点处切分，使每段 $s$ 具有稳定的固定向外法线方向 $n_s$。

3. **预构建固定走廊 $V_s$ 与候选位移 $\mathcal{D}_s$**：
   - 位移搜索集合为整数像素位移 $d \in \{-8, -7, \dots, 0, \dots, 7, 8\}$（上限 $8\,\text{px}$ 对应 $64\times 64$ token 网格在 $512\times 512$ 原图上的步长），必含 $d = 0$。
   - 在粗边界 $\partial M_0$ 的 $\pm 8\,\text{px}$ 形态学窄带内，每个像素按最近弧长距离及段序号优先级（`s` 较小者优先）唯一归属到轮廓段 $s$（Voronoi 划分，消除相邻段共享像素冲突），并计算其沿段外法线 $n_s$ 的有符号整数层级位移 $u_s(x) \in \{-8, \dots, +8\}$（$M_0(x)=1$ 内部为 $u_s(x) \in \{-7, \dots, 0\}$，$M_0(x)=0$ 外部为 $u_s(x) \in \{+1, \dots, +8\}$）：
     - 当 $d > 0$（外扩 $d$ 像素）：新增集合 $A_s^+(d) = \{x \in V_s : M_0(x)=0,\; 1 \le u_s(x) \le d\}$，移除集合 $A_s^-(d) = \emptyset$；
     - 当 $d < 0$（内缩 $|d|$ 像素）：新增集合 $A_s^+(d) = \emptyset$，移除集合 $A_s^-(d) = \{x \in V_s : M_0(x)=1,\; d + 1 \le u_s(x) \le 0\}$；
     - 当 $d = 0$：$A_s^+(0) = \emptyset,\; A_s^-(0) = \emptyset$。
   - **走廊边界与拓扑硬约束**：
     - 内侧对岸保护：距同一连通域非相邻对岸边界 $\le 2\,\text{px}$ 的内部像素不纳入 $V_s$，防止内缩切断或删除连通域；
     - 外侧邻域保护：距图像边缘之外、或距其他连通域 $\le 2\,\text{px}$ 的外部像素不纳入 $V_s$，防止相邻目标合并；
     - 观测完整性要求：候选位移 $d \ne 0$ 必须在段弧长方向上至少覆盖 `min_valid_column_coverage = 75%` 的有效法线列（且每步新增/移除像素非空），否则该 $d$ 从 $\mathcal{D}_s$ 中剔除（拒绝证据不完整候选）；
     - 拓扑不变量检查：单段候选掩膜 $M_{s,d}$ 及多段按固定顺序（按连通域编号、再按校准后收益裕度 $G_s(d_s^\star) - \tau^{(m)}$ 降序、段序号升序）合并时，必须保持 8-连通前景组件数 $b_0$ 与 4-连通背景孔洞数 $b_1$ 与 $M_0$ 完全相等（禁止产生新连通域、删除已有目标、生成孔洞或合并相邻目标）。

4. **亮度提取与边界安全局部趋势去除**：
   - 亮度 $I(x) = 0.299 R(x) + 0.587 G(x) + 0.114 B(x) \in [0, 1]$。
   - 局部低频趋势 $m(x)$ 采用**完全独立于候选位移 $d$ 与粗掩膜边界位置**的保边双边低通滤波（`trend_radius_px = 8`, `trend_sigma_spatial_px = 6.0`, `trend_sigma_range = 0.12`）：
     $$m(x) = \frac{\sum_{\|\xi\|_\infty \le 8} \exp\!\left(-\frac{\|\xi\|_2^2}{2\sigma_{\text{sp}}^2} - \frac{(I(x+\xi)-I(x))^2}{2\sigma_{\text{rg}}^2}\right) I(x+\xi)}{\sum_{\|\xi\|_\infty \le 8} \exp\!\left(-\frac{\|\xi\|_2^2}{2\sigma_{\text{sp}}^2} - \frac{(I(x+\xi)-I(x))^2}{2\sigma_{\text{rg}}^2}\right)}, \qquad r(x) = I(x) - m(x)$$
   - 值域核 $\sigma_{\text{rg}} = 0.12$ 自动阻断阵列与背景之间的大幅阶跃亮度跳变，避免跨边界低通滤波将内部周期条带泄漏到阵列外侧，同时无损保留阵列内部细微周期条带波动。

## 3. 内部载波拟合、空间留出验证与冻结（2.2 节锁定规则）

1. **拟合区 $F$ 与留出验证区 $H$ 的严格空间分离**：
   - 对连通域 $C_c$ 进行半径 $8\,\text{px}$ 的形态学腐蚀得到纯内部域 $I_c = \operatorname{erode}_8(C_c)$，保证 $I_c \cap (\bigcup_s V_s) = \emptyset$（与所有候选评分走廊严格空间分离）。
   - 将 $I_c$ 按 $12\times 12$ 像素空间棋盘格划分为交替块，并在相邻块交界处留出 `fit_holdout_guard_gap_px = 2` 像素的隔离带：偶校验块构成拟合区 $F$，奇校验块构成留出验证区 $H$（若小目标棋盘有效像素不足，则沿主轴中线切分为左右两半并留 $2\,\text{px}$ 隔离带分别作为 $F$ 与 $H$）。
   - 样本量门槛：要求 $|F| \ge 48$ 且 $|H| \ge 32$，且留出区总能量 $\sum_{x\in H} r(x)^2 \ge 10^{-6}$；否则直接回退（`insufficient_interior_or_holdout`）。

2. **支持集辅助周期范围与候选频率提议**：
   - 从当前 Episode 的 $K$ 张支持图 GT 掩膜内部（腐蚀 $4\,\text{px}$）提取显著周期分量的波长分布，结合 2m 采样物理极限 $[2.5, 14.0]\,\text{px}$ 确定可用周期范围 $[\lambda_{\min}, \lambda_{\max}]$（默认 $[2.8, 12.0]\,\text{px}$；对于面积 $< 1024\,\text{px}$ 的查询小目标，若支持集存在可靠周期库则收缩至支持集周期范围 $\pm 25\%$）。
   - 在查询连通域内部提取二维自相关与 $64\times 64$ 零填充二维功率谱峰值，并结合内部结构张量主方向提示（仅用于补充方向候选，绝不用轮廓法线替代条带方向），在环带 $\|\omega\| \in [2\pi/\lambda_{\max}, 2\pi/\lambda_{\min}]$ 内提议前 `top_candidate_frequencies = 12` 个候选波矢 $\omega$（并在 $F$ 上做局部网格微调）。

3. **加权最小二乘拟合与留出块预测验证**：
   - 以 $F$ 的质心为固定坐标原点 $x_0$，在 $F$ 上求解（权重 $w_x \equiv 1$，与任何 $d$ 无关）：
     $$\hat{r}_\omega(x) = a\cos\bigl(\omega^\top(x-x_0)\bigr) + b\sin\bigl(\omega^\top(x-x_0)\bigr)$$
   - 检查 $2\times 2$ 正规方程矩阵条件数 $\operatorname{cond}(M_\omega) \le 50.0$，且内部跨度沿 $\omega$ 方向至少覆盖 `min_span_periods = 2.0` 个周期。
   - 在空间分离的留出块 $H$ 上计算决定系数：
     $$S_H(\omega) = 1 - \frac{\sum_{x\in H}[r(x) - \hat{r}_\omega(x)]^2}{\sum_{x\in H} r(x)^2}$$
   - 选取 $\omega^\star = \arg\max_\omega S_H(\omega)$。必须同时满足：
     1. $S_H(\omega^\star) \ge \max(0.05,\; S_{H,\text{sup\_floor}})$（严格优于零载波 $S_H = 0$）；
     2. 在 $F$ 与 $H$ 上分别拟合的相位余弦一致性 $\cos(\phi_F - \phi_H) \ge 0.50$。
   - 若不满足，直接回退（`carrier_holdout_unverified`）。通过验证后**立即冻结** $(\omega^\star, \hat{a}, \hat{b})$ 及由留出残差 MAD 稳健估计的方差尺度 $\sigma_s^2 = \max\bigl(\operatorname{MAD\_var}(r_H - \hat{r}_{\omega^\star, H}),\; \sigma_{\text{floor}}^2\bigr)$。

## 4. 相位证据、语义护栏与支持集经验门槛（2.3 & 2.4 节锁定规则）

1. **像素级相位续接证据与位移收益**：
   - 在固定有效评分域 $V_s$ 上：
     $$e_s(x) = \frac{r(x)^2 - [r(x) - \hat{r}_\omega(x)]^2}{2\sigma_s^2}$$
   - 候选位移 $d \in \mathcal{D}_s$ 的总收益与弧长归一化收益（以消除不同段长量纲差异，保证支持集分块与查询段尺度一致）：
     $$G_s(d) = \frac{1}{L_s}\left(\sum_{x\in A_s^+(d)} e_s(x) - \sum_{x\in A_s^-(d)} e_s(x)\right), \qquad G_s(0) = 0$$
     其中 $L_s$ 为段 $s$ 的有效弧长列数（对同一段 $s$，$L_s$ 为正常数，不改变 $\arg\max_d G_s(d)$ 的排序与正负号，且使支持集零移动门槛 $\tau^{(m)}$ 与查询段量纲严格对齐）。
   - 同分打破规则（容差 $10^{-12}$）：优先 $d=0$ $\to$ 优先 $|d|$ 较小 $\to$ 优先内移（$d<0$）再外移（$d>0$）。

2. **语义护栏 $p_{\text{floor}}$**：
   - 外移候选 $d > 0$ 须满足 $\operatorname{mean}_{x\in A_s^+(d)} P_0(x) \ge p_{\text{floor}}$（组 `H` 除外）。
   - 当 $K \ge 2$ 时：对每张支持图 $i \in \{1, \dots, K\}$，用其余 $K-1$ 张支持图运行 `run_iter5_episode` 得到真正留出预测 $P_0^{(-i)}$，在支持图 $i$ 的 GT 正前景内侧 $8\,\text{px}$ 边缘带（优先漏分带 $P_0^{(-i)}(x) < 0.5$；若漏分像素 $<16$ 个则取全部内侧 $8\,\text{px}$ 正边缘带）上取 $25\%$ 分位数，并截断至 $[0.20, 0.48]$（绝不使用 $0.5$）。
   - 当 $K = 1$ 时：因无法在不泄漏本图标签的前提下构造多图留出预测，执行预先锁定的保守回退策略——**$K=1$ 时禁止所有外移候选（仅允许 $d \le 0$）**，并在诊断报告中单列其影响。

3. **支持集空间分块零移动经验门槛 $\tau^{(m)} = Q_{1-\alpha}(\{T_i^{(m)}\})$**：
   - 显著性水平锁定为 $\alpha = 0.05$（即 $95\%$ 经验分位数）。
   - 以支持图中的**独立空间分块**（$40\times 40$ 像素网格块，且距真实 GT 边界 $> 8\,\text{px}$ 的纯光伏内部块与纯背景块）作为校准单元 $i$：
     - 在每个纯内部块或纯背景块中央放置一条虚拟测试轮廓段（两侧同属纯内部或同属纯背景，任何非零移动均为零假设下的虚假移动），用与查询图完全相同的载波拟合/留出、走廊构造、外移护栏和评分函数计算最大零移动增益 $T_i^{(m)} = \max_{d\in\mathcal{D}_i} G_i^{(m)}(d)$。
     - 当当前支持集生成的有效校准空间块数 $\ge N_{\min} = 4$ 时，取 $\tau^{(m)} = Q_{0.95}(\{T_i^{(m)}\})$；
     - 当有效校准空间块数 $< 4$ 时，采用 `configs/phase_boundary_locked.json` 中预先锁定的保守门槛回退值 `fallback_gain_per_px`，并记录校准回退比例。

## 5. 必做消融（A–H）与等移动预算匹配规则（第 3 节锁定规则）

- **A (`A_M3_Pruned`)**：原始 `M3_Pruned_Ref`，不移动。
- **B (`B_GradAlign`)**：局部 Scharr 梯度对齐，比较候选边界与原边界上的归一化梯度幅值增益。
- **C (`C_TexVar`)**：普通纹理变化，比较 $5\times 5$ 局部残差方差相对内部/外部参考方差的对数似然差，不估计条带相位。
- **D (`D_BilateralTerm`)**：双侧周期终止，共享拟合周期位移 $v = 2\pi\omega^\star/\|\omega^\star\|^2$，计算走廊内侧与外侧的三点对称加权相关差 $E(d) = R^-(d) - R^+(d)$，以 $G_s^{(D)}(d) = E(d) - E(0)$ 评分。
- **E (`E_FreqAmp_NoPhase`)**：有频率和幅值、无内部相位。使用与 `F` 完全相同的 $\omega^\star$、$A = \sqrt{\hat{a}^2+\hat{b}^2}$、$\sigma_s$、候选集与像素域 $V_s$，将走廊按弧长每 $4\,\text{px}$ 划分为局部块 $B \in \mathcal{B}_s$，在 16 点均匀相位网格 $\Phi = \{2\pi k/16\}_{k=0}^{15}$ 上通过 `logsumexp` 边缘化相位计算 $G_{\text{amp}}(d) = \frac{1}{L_s}[L_{\text{amp}}(M_{s,d}) - L_{\text{amp}}(M_0)]$。
- **F (`F_FullPhase`)**：完整方法（冻结内部相位）。
- **G (`G_PhaseCounterfactual`)**：相位反事实。将 `F` 的冻结相位分别加上 $\gamma \in \{\pi/2, \pi, 3\pi/2\}$，不重估任何参数或有效像素。分别报告三个角度及三角度平均表现（含各自支持集标定门槛与固定主方法门槛 $\tau^{(F)}$ 两组受控结果）。
- **H (`H_NoSemGuard`)**：从 `F` 仅去掉外移概率护栏 $p_{\text{floor}}$，保留其余全部几何与支持集回退约束。

**同等移动预算匹配协议（Matched Movement Budget）**：
- 在 `D / E / F / G` 共同可评估的轮廓段集合上，以双方自然触发移动弧长的较小值 $L_{\text{target}} = \min(L_{\text{moved}}^{(m_1)}, L_{\text{moved}}^{(m_2)})$ 为预算上限；
- 按位移绝对值分三档 $\{1..2\}, \{3..4\}, \{5..8\}\,\text{px}$，在每档内按各自校准后收益裕度 $G_s(d_s^\star) - \tau^{(m)}$ 从高到低排序，截取相同的移动弧长预算（绝不使用查询 GT 排序，也不逼迫自然未触发的段移动）；
- 若共同移动弧长占比 `< 1%` 或匹配后平均绝对位移差 `> 0.75 px`，机制归因必须判定为“**证据不足**”。
