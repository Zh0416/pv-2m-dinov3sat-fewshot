## 1. 旧模块 ③（`M3_DeformGrad_Old`）在 `0.8m` 失效的根因

旧版基于 Sobel 梯度幅值与内外环对比的可变形轮廓在 `2m` 上有效，但在 `0.8m`（`PV663`）上出现系统性退化（`BF1@2` `-0.060 ~ -0.062`，`Dice` `-0.010`），核心原因有五点：

1. **像素界面半像素偏移**：旧实现在 `pts + d * n` 处采样而非 `pts + (d + 0.5) * n`，引入系统性 `+0.5 px` 偏差。
2. **高频条纹与阴影陷阱**：在 `0.8m` 下，光伏阵列内部组件缝隙、支架间距（`1~2 px`）和阴影的梯度幅值甚至高于外边缘，单尺度梯度驱动轮廓向阵列内部坍缩或向邻近道路/田埂跳跃（平均位移高达 `3.60 ~ 4.17 px`）。
3. **外环背景污染**：旧版统计 `ring_out` 作为外部参考，在水面/鱼塘等场景中易采到远处堤坝或道路，产生向外扩张的“气球力”。
4. **已精准边界漂移**：缺乏语义不确定带与自锁保护，原本已经对齐良好的高清掩膜也会被强拉偏。
5. **整圈回退过于粗暴**：局部自交时整条轮廓全部回退（`PV-100scence` 高达 `766` 次，`PV663` 高达 `218` 次），导致好段和坏段一并失效。

## 2. 原创改进方案：PBDC（Interior-Core-Anchored Asymmetric Step & Semantic-Uncertainty Deformable Contour）

一套**无需训练、单一锁定参数集**同时适配 `2m` 与 `0.8m` 的边界精修模块，核心设计包括：

1. **半像素精确物理界面**：以 `iface_xy = pts_xy + (d + 0.5) * normals_xy` 定位真实像素边界，消除半像素系统偏差。
2. **仅内部核心原型锚定（`mu_in, sig_in`）**：彻底移除易受污染的 `ring_out`，在 3 通道感知拮抗色空间 `[L, R-G, B-0.5(R+G)]` 中仅用高置信内部核心统计光伏特征分布，对等亮度色度边同样敏感。
3. **多尺度方向一致阶跃 × 内外非对称性 × 内部纯度门控**：
   - 联合 `1.0 px` 与 `2.8 px` 跨距的方向阶跃响应；
   - 乘以非对称项 `ReLU(phi_out - phi_in)` 与内部光伏纯度门控，从物理上抑制 `<= 2 px` 光伏内部组件缝隙（两侧均为光伏，非对称项归零）及“道路-草地”假边（内侧非光伏，纯度门控归零）。
4. **零正向气球力 + 语义不确定带 + 已对齐自锁**：
   - 区域一致性改为严格单边否决惩罚（`<= 0`），彻底杜绝无约束外扩；
   - 仅在语义概率不确定带 `[max(p_floor, 0.34), 0.72]` 内允许大步移动，并加入 `1.28x` 已对齐自锁（`self_lock_ratio = 0.28`）。
5. **8 扇区局部拓扑回退 + 锁角闭环动态规划**：局部自交仅回退对应扇区而非整圈（整圈回退减少 **97% ~ 100%**），并加速 DP 搜索约 `3 ~ 4×`。

  - `2m`：旧版 `89 / 766 / 713` $\to$ **`PBDC` `6 / 7 / 5`**
  - `0.8m`：旧版 `49 / 218 / 174` $\to$ **`PBDC` `0 / 2 / 6`**

## 4. 结论

**Iter 1 (`PBDC`) 一次通过跨分辨率双数据集验证**：在不针对分辨率切换任何超参数的前提下，在 `2m` 与 `0.8m` 的全部 6 个 `(Dataset × Shot)` 设定下均实现 `BF1@1`、`BF1@2`、`Dice`、`IoU` 与 `Sm<5R` 全线正收益（`2m` 全部 3 个 Shot 的 `BF1@2` 与 `Dice` 95% CI 严格 `> 0`，`0.8m` 全部 3 个 Shot 的 `BF1@1` 95% CI 严格 `> 0` 且相对旧版提升 `+0.071 ~ +0.086`），同时完整保持 `NegFP` 与 `Precision` 稳定。暂无需为追求微弱波动做可能过拟合子集的 Iter 2，可直接作为新版模块 ③ 候选合入主线或继续做全量终审。
